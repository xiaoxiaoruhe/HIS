1.提交审批

业务流程

```java
1.查询明细列表，先校验参数和明细状态，确保单据是草稿且没有重复项
2.遍历明细列表，根据单据号，库房号查找单据明细对应的库存
3.验证自己和别人有没有持有该库存的锁，没有就加
4.冻结此时快照
5.修改明细状态
6.装载VO返回
```

2.审批通过

```java
1. 取出快照里的账面数量
2. 取出单据明细里的实盘数量
3. 计算差异 = 实盘 - 账面
4. 如果有差异，生成盘盈/盘亏调整单，真正扣减或增加库存
5. 释放锁
6. 单据状态改为 APPROVED
```
